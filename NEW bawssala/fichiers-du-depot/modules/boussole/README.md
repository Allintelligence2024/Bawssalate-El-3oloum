# البوصلة | Laboratoire embarqué dans Boussole Lite

Dans la barre du bas, **البوصلة** lance directement le laboratoire (même origine, pas de Drive ni de second service). «تمارين المنهجية الأخرى» donne accès aux ateliers annexes. Dans un exercice, l’aide ouvre le même document dans un dialogue sans démonter l’exercice. La rubrique de ressources du laboratoire ouvre deux vrais PDF et permet de télécharger le HTML autonome. Le module ne lit pas le compte Lite, n’envoie aucun score, et utilise sa propre clé de brouillon. L’application conserve ses règles de connexion ; le document `/boussole/index.html` est consultable directement sans profil.

**Construction.** À la racine de l’application, `npm ci && npm run build` suffit : le HTML et les deux PDF sont versionnés dans `public/boussole/` et participent au manifeste hors ligne. Pour **modifier le laboratoire** : dans `modules/boussole`, exécuter `npm ci`, `npm run typecheck`, `npm run build`, puis rebâtir l’application depuis la racine. Les ressources nécessaires sont intégrées au HTML. Pour les essais du labo : `npx playwright install chromium && npm test` dans ce dossier. Ne pas déployer ce dossier à la place de l’application.

**Sources.** Bac algérien 2022, sciences expérimentales, sujet 1 : exercice 2, p. 2–3 (circuit, douze enregistrements et deux figures) ; exercice 3, p. 4, document 1, figure جـ (laminine chez le patient). [Sujet consulté](https://drive.google.com/file/d/12B1vbw5OP1MBkJEJU121f1Ph8apNuf6v/view) · [correction consultée](https://drive.google.com/file/d/1MVcF_q24A014thaFa589991aKP2l-s4L/view), notamment p. 4 pour la lecture de la figure جـ. Le graphe original du patient est recadré, jamais reconstruit ; les mesures retenues à 6,25 et 12,5 µg/ml sont 10 et 20 % d’expression. Ce sont des données d’examen, pas une recommandation thérapeutique. Le mini-cas ne remplace pas l’exercice complet. Les deux cas quantitatifs sur l’enzyme et l’immunité sont des entraînements, pas les annales. Les illustrations de couverture ne sont pas des preuves.

**Papier.** `cahier-bac-2022.pdf` : synapses (trois pages adaptées) puis membrane (question 1 seulement de l’exercice 1, une page), sans corrigé. `memo.pdf` : huit familles de consignes, une page. Le sujet et le corrigé d’origine restent distincts. Les aides «رموز الموضوع الأصلي», rapprochement stimulation/injection, et comparaison après écriture sont facultatives. Aucun chronomètre ni score de maîtrise n’a été ajouté.

Les témoins historiques 1.4 ب et 1.5 ne font pas partie de cette migration et ne sont pas modifiés. Les licences de la police et des dépendances du HTML sont jointes dans `assets/` et dans le HTML autonome.

## 5. Limites et usage

- Lexique manuel (`MOTS_UNITE`) : un relecteur enseignant doit valider la section 3 ; toute correction se fait dans le script, jamais dans `priorites.ts`.
- Les scans 2013–2015 et 2024–2026 manquent : la tendance récente (2024–2026) est donc **sous-représentée**.
- Usage dans l'app : phases du mode intensif (J-60 = priorité 1, J-30 = 1–2), badge discret dans مساري. Aucun effet sur le verrouillage séquentiel hors mode intensif.

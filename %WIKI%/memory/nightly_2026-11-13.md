# Nuitée 2026-11-13

## Résumé de la journée
- Installé et validé REA (455k étoiles) et Craft Anything (30.3k) sur Windows
- Tests CLI réussis : `craft-anything-cli doctor` = healthy:true, `js_app_map --deep` = 73 fichiers analysés

## Faits mémorisés
1. **Installation portable avant MSI** : MSI Windows refuse si non-admin (exit 1619)
2. **CRA fonctionne en CLI** : et non seulement en desktop
3. **Clean room vs Deep mode** : la contrainte Clean room bloque `core-target-open` et `js_app_map` sans `--deep`
4. **REA + CRA** : le chemin recommandé pour Windows (ERA n'est pas validé)

## Événements notables
- Téléchargement 58 Mo MSI refusé (non-admin) → basculement vers ZIP portable
- Terminal Windows ne pilote pas l'interface graphique → tests GUI nécessitent l'UI physique

## Patterns identifiés
- L'outil reverse engineering Windows nécessite toujours Node.js 22+ et npm 12+
- Les packages npm (`rea-agents`) installés globalement fonctionnent sans configuration supplémentaire
- Les tests CLI sont plus reproductibles que les tests GUI
